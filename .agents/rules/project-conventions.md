# Reglas propuestas

Este directorio contiene reglas temáticas con alcance, justificación basada en el repositorio y guía específica:

- [Contratos y mocks](contracts-and-mocks.md): tipos compartidos y fuentes de datos de ejemplo.

- [Seguridad y ejecución](security-and-runtime.md): CORS, depurador y puertos publicados.
- [Testing](testing.md): cobertura por flujo y comandos disponibles.
- [Documentación y DX](documentation-and-dx.md): instrucciones de configuración ejecutables.
